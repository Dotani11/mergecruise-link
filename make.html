🔗 Merge Cruise reward → Facebook link

Paste a mergecruise://… reward link. You'll get an https link you can post on Facebook/Instagram. It opens the game on the reward (or sends people to the store if they don't have the app).

⚠️ When opened inside the Facebook/Instagram in-app browser, the page will tell users to tap ⋯ → “Open in browser” first — that's a platform limit, not a bug. On Android it usually opens straight away.
